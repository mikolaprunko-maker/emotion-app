# 🎭 AI-перекладач емоцій

Веб-застосунок, який за допомогою штучного інтелекту визначає емоцію в тексті користувача, показує відповідне емодзі, рівень упевненості, пояснення, практичну пораду та надихаючу цитату.

**Автор:** Прунько М.С., група АКП-25-3К, ІФНТУНГ
**Дисципліна:** Основні принципи та можливості ШІ, практична робота № 9 (ідея № 1)
**Демо:** `https://<назва>.onrender.com`

## Технології

| Частина | Технологія |
|---|---|
| Backend | Python 3.14, **Flask** |
| ШІ | **Google Gemini API** через бібліотеку `google-genai` |
| Структурована відповідь ШІ | JSON Schema, згенерована з моделі **Pydantic** |
| Frontend | HTML, CSS, JavaScript (fetch API) |
| Продакшн-сервер | gunicorn |
| Хостинг | Render.com |

## Як це працює

1. Користувач вводить текст і натискає «Визначити емоцію».
2. JavaScript надсилає POST-запит `/api/analyze` на сервер Flask.
3. Flask перевіряє текст (не порожній, від 3 до 1000 символів) і надсилає його в Gemini разом із системною інструкцією та JSON-схемою відповіді.
4. Gemini повертає JSON: емоція, додаткові емоції, впевненість, пояснення, порада, цитата.
5. Сервер перевіряє відповідь через Pydantic, приводить емоцію до списку з 10 відомих емоцій, додає емодзі і повертає результат на сторінку.

Якщо одна модель Gemini недоступна або вичерпано її ліміт, сервер автоматично пробує наступну зі списку.

## Локальний запуск (Windows)

```
cd emotion_app
py -3.14 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Ключ Gemini (aistudio.google.com → Get API key) покладіть у файл `api_key.txt` або задайте змінну середовища `GEMINI_API_KEY`. Сайт відкриється за адресою http://127.0.0.1:5000

## Публікація на Render

1. Завантажте проєкт на GitHub (без `api_key.txt`).
2. На render.com: **New → Web Service** → виберіть репозиторій.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. Instance type: **Free**.
6. У розділі **Environment** додайте змінну `GEMINI_API_KEY` зі своїм ключем.

## API

| Метод | Адреса | Опис |
|---|---|---|
| GET | `/` | Головна сторінка |
| POST | `/api/analyze` | Тіло `{"text": "..."}` → JSON з результатом аналізу |
| GET | `/api/health` | Стан сервера та чи налаштовано ключ ШІ |

## Опрацювання помилок

| Ситуація | Реакція |
|---|---|
| Порожній, закороткий або задовгий текст | Повідомлення з поясненням, код 400 |
| Ключ Gemini не налаштований | «На сервері не налаштовано ключ…», код 500 |
| Ключ недійсний | «Ключ Gemini API недійсний…», код 500 |
| Модель недоступна (404) або ліміт (429) | Автоматичний перехід до наступної моделі |
| Вичерпано ліміт на всіх моделях | «Вичерпано безкоштовний ліміт…», код 429 |
| Збій на боці Google або немає інтернету | «Сервіс ШІ тимчасово недоступний…», код 503 |
| ШІ повернув неправильний JSON | Повторна спроба з іншою моделлю |
| ШІ назвав емоцію поза списком | Замінюється на «нейтрально» |

> Безкоштовний сервер Render «засинає» після 15 хвилин без відвідувачів, тому перше відкриття сайту може тривати до хвилини.
